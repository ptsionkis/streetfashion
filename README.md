# STATION STREETWEAR

React/Vite storefront project for the Station Streetwear redesign.

> DEVELOPMENT PREVIEW — not yet a working ecommerce backend. Demo catalog, cart and wishlist only. No real payments, inventory, orders or customer records are handled by this code.

## Run locally

```bash
npm install
npm run dev
npm run build
```

## Connect to Base44

1. Open the GitHub integration in your Base44 app and connect `ptsionkis/streetfashion` on `main`.
2. Verify the project imports and builds before enabling or publishing.
3. Verify synchronization separately: commits are not the same as a published live release.

## Before production
- Connect products, variants and stock to secure server-side data.
- Implement pricing, stock reservation, orders, hosted checkout and signed payment webhooks server-side.
- Configure customer permissions, shipping, invoices, GDPR, SEO and redirects.
- Never store credentials or private customer data in this public repository.

For further development consult `AGENTS.md`.
