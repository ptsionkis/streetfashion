# STATION STREETWEAR — Development rules

This is a storefront prototype using React/Vite. The site will ultimately run within the user's Base44 app after import.

- Preserve editorial dark streetwear aesthetics and responsive mobile design.
- All products, inventory and pricing currently shown are demo fixtures, not commercial offers.
- Never claim payment processing, shipping, actual accounts or subscriptions are implemented if not connected.
- Avoid putting credentials, private API keys or customer data in this public repository.
- Implement secure authorization and server-side price/stock validation before handling real orders.
- Use feature branches and pull requests for significant changes; don't publish production without approval.
- Keep checkout disabled until a hosted PSP, signed webhooks, inventory reservations and end-to-end QA are validated.
- Treat Base44-specific APIs as unverified until tested in the real Base44 project.
